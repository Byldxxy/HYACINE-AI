# WebUI 场景素材

| 文件 | 结构 | 使用组件 |
| --- | --- | --- |
| `emblems.png` | 3 × 2 透明徽记图集 | `ArtEmblem` |
| `hyacine-poses.png` | 招手、思考、微笑三种全身姿势 | `CharacterDisplay` |
| `../sky-garden.jpg` | 云庭场景背景 | 工作区背景样式 |

素材为生成式界面插画，不是官方游戏动画。姿势图集按实际轮廓裁切，保留透明通道，通过静态姿势过渡、轻量摆动与指针视差呈现；不包含骨骼绑定。

素材由多个页面共享，避免重复加载。自定义本地立绘不使用该姿势图集。桌宠模型、动作与本地角色参考图独立管理；私有文件不包含在这些发布素材中。角色形象的原作权利不因代码许可证而改变。
